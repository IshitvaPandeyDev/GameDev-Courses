# 🚗 Delivery Dash - 2D

![Unity Version](https://img.shields.io/badge/Unity-6-lightgrey)
![C#](https://img.shields.io/badge/Language-C%23-blue)
![License](https://img.shields.io/badge/License-MIT-green)

**Delivery Dash** is a fast-paced, top-down 2D driving game built in Unity. The objective is simple: navigate the map, pick up packages, and deliver them to designated customers as quickly as possible! 

This project was developed as part of a GameDev 2D course tutorial, focusing on core Unity 2D mechanics, physics, and input handling.

---

## 🎮 Gameplay Highlights

- **Dynamic Driving:** Smooth top-down car controller utilizing Unity's 2D physics engine.
- **Delivery System:** Drive over packages to pick them up, and navigate to the drop-off zones to complete deliveries.
- **Speed Boosts:** Drive over boost pads to accelerate your vehicle and improve your delivery times.
- **Dynamic Camera:** Utilizes Unity Cinemachine to smoothly track the player's vehicle across the map.

---

## 🛠️ Technologies & Concepts Used

- **Engine:** Unity 6
- **Language:** C#
- **Key Concepts Learned:**
  - `Input.GetAxis()` for responsive steering and acceleration.
  - `OnCollisionEnter2D` and `OnTriggerEnter2D` for item pickups and deliveries.
  - Sprite rendering and layer sorting.
  - Basic UI updates and scene management.
  - Unity Cinemachine Virtual Cameras.

## 🚀 Installation & Setup

To run this project locally on your machine:

1. Clone this repository:
   ```bash
   git clone [https://github.com/IshitvaPandeyDev/GameDev-Courses.git](https://github.com/IshitvaPandeyDev/GameDev-Courses.git)
   ```
2. Open **Unity Hub**.
3. Click on **Open** -> **Add project from disk**.
4. Navigate to the `2D/Delivery-Dash-Tut` folder inside the cloned repository and select it.
5. Open the `Main` (or `Level1`) scene located in the `Assets/Scenes` folder.
6. Press the **Play** button at the top of the Unity Editor to test the game!
