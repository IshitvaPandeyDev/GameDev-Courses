## 🛠️ Technical Skills Demonstrated

Throughout these projects, I am actively applying and refining the following technical concepts:

- **C# Scripting:** Writing clean, modular, and performant C# code to control game logic, manage state, and handle user inputs.
- **Unity Physics Engine:** Mastering both discrete and continuous 2D collisions (`OnCollisionEnter2D`, `OnTriggerEnter2D`), manipulating Rigidbody mass/gravity, and applying directional forces.
- **Cinematics & Cameras:** Utilizing Unity Cinemachine for smooth, professional camera tracking, bounds enforcement, and dynamic framing.
- **Game Feel & Polish:** Enhancing player feedback through integrated Particle Systems, screen shake, and responsive controls.
- **Environment Design:** Building scalable levels using Tilemaps, Sprite rendering, and layer sorting techniques.

## 🚀 How to Run the Projects

To explore the source code or play these games locally, you will need **Unity Hub** and a compatible version of the Unity Editor (built primarily in Unity 6).

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/IshitvaPandeyDev/GameDev-Courses.git](https://github.com/IshitvaPandeyDev/GameDev-Courses.git)
   ```
2. **Open Unity Hub.**
3. Click on **Open** -> **Add project from disk**.
4. Navigate into the cloned repository and select the specific project folder you wish to load (e.g., `2D/Delivery-Dash-Tut`).
5. Once the editor loads, navigate to the `Assets/Scenes` folder in the Project window.
6. Open the main level scene and hit the **Play** button at the top of the editor.
