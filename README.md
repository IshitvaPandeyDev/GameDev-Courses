##Tech Stack & Tools:
(i) Game Engine: Unity (2D & 3D)
(ii) Programming Language: C#
(iii) Version Control: Git & GitHub
(iv) Learning Platforms: GameDev.tv & Udemy

##How to Run Any Project
(i)Clone the repository: git clone [https://github.com/IshitvaPandeyDev/GameDev-Courses.git](https://github.com/IshitvaPandeyDev/GameDev-Courses.git)
(ii)Import into Unity Hub:
  -Open Unity Hub.
  -Click Add -> Add project from disk.
  -Select any project directory from within 2D/ or 3D/.
(iii)Launch the Project:
  -Open the project in Unity Editor.
  -Locate and open the main scene inside the Assets/Scenes folder.
